**Ключевые архитектурные решения:**
- Стек: Nuxt 4 + `@bitrix24/b24ui-nuxt` + Tailwind v4 + TypeScript → статика → собственный хостинг → `bx-shef.by`
- Шрифты self-hosted (`@fontsource/rubik` + `@fontsource/roboto-mono`) — не зависит от Google Fonts CDN
- CSP-meta в `nuxt.config.ts` с broad `https:` allowlist
- Форма заявок — embed Битрикс24 (две-script-теговая схема: marker + loader с cache-buster)
- Embed-параметры формы — публичные, вшиты как defaults в `nuxt.config.ts`, переопределяются через `vars` в GitHub Actions
- Счётчик посещений — `counterapi.dev` (без cookies, без регистрации)
